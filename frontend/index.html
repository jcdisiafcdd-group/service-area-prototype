Walking-time note

The estimate uses the selected constant speed on the official pedestrian network. It does not add traffic-light or crossing delays, slope/gradient speed penalties, accessibility-barrier restrictions, or special speeds for stairs, escalators, lifts, and travelators. Routes start and end at snapped network nodes, so short access distances are excluded.
